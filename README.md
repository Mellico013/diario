# Um pedacinho de nós

Um diário digital em forma de livro, com páginas que viram por botões, pelos pontos de navegação, pelas setas do teclado ou por gesto no celular. É uma página estática, sem dependências de build, pronta para publicar no GitHub Pages.

## Fotos e música

As fotos ficam em `assets/`: `capa.jpg` aparece na abertura; `foto-quebra-cabeca.jpg` é a imagem do jogo; `foto-01.jpg` a `foto-04.jpg` aparecem no mural e na cabine. As imagens enviadas foram convertidas para JPEG e otimizadas para o site.

O botão **Só Nós Dois** abre o player oficial do Spotify para a faixa de Tim Bernardes. É preciso conexão com a internet; o Spotify pode pedir login para tocar a música completa.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie estes arquivos para a raiz dele.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)`, e salve.
4. Aguarde o endereço do site aparecer na própria página do GitHub Pages.

Não é preciso instalar nada nem gerar uma pasta de build.
